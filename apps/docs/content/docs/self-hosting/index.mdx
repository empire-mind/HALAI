HALAI runs locally by default. The harness listens on loopback, agent CLIs run on your machine and application state uses the existing `~/.openmausbot` location.

For a remote Docker desktop with the harness still on your computer, see [Your own VPS (BYO)](/docs/computers/byo-vps).

## Choose the build for your server

Use [HALAI releases](https://github.com/empire-mind/HALAI/releases) for the server images and instructions published by EmpireMind. For a source evaluation, [install HALAI from a pinned revision](/docs/getting-started/installation#source-workspace) in an isolated workspace. The [OpenMausBot VPS reference](/docs/self-hosting/deploy-vps) documents the upstream one-command installer and its distribution.

## Connect a device

1. Keep the harness on loopback and follow the [networking guide](/docs/self-hosting/networking) for the approved connection method.
2. Install and authenticate the agent CLIs you need using the same operating-system account that runs the server.
3. Create a pairing link for the intended device. Use **＋ → Connect to a server** in the desktop app, or open the link in the browser on the device you are pairing.
4. Check the list of paired devices and remove access for devices no longer in use.

## Back up the workspace

Stop the server before a filesystem backup. Follow [Data and backups](/docs/self-hosting/data-and-backups) for the workspace data, browser state and engine credentials. Keep credentials in the approved secret store and rehearse restoration on an isolated copy.

## Optional services

Agents, connected apps, cloud computers and hosted voice use their own providers when enabled. Confirm the provider for your build before connecting accounts. See [Permissions and secrets](/docs/security/permissions-and-secrets) and [Model providers](/docs/providers/model-providers).

## Run headless during development

```bash
pnpm install --frozen-lockfile
pnpm dev:server
```

The main harness listens on `127.0.0.1:8799` by default. Keep it private; it owns agent processes, approvals, computers, and workspace configuration.
