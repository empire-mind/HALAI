## Released builds

Use [HALAI releases](https://github.com/empire-mind/HALAI/releases) for builds published by EmpireMind. Each published release should identify the tested platforms, architecture, signing status and source revision.

## Source workspace

Use Node.js 24 or newer, pnpm 10.33.0 and a supported agent CLI. Start in a clean development checkout and use an isolated workspace for evaluation.

```bash
git clone https://github.com/empire-mind/HALAI.git
cd HALAI
pnpm install --frozen-lockfile
```

The root scripts launch the development server and renderer. Open them in separate terminals.

```bash
pnpm dev:server
pnpm dev
```

To launch the Electron development shell, use `pnpm dev:desktop` from the same checkout. Platform prerequisites and provider account setup are described in the [engine reference](../providers/index.mdx).

## First agent

1. Install one supported agent CLI from the provider you choose.
2. Complete sign-in with that provider on the machine running the workspace.
3. Open HALAI, select a ready engine and give it one small task to verify the connection.

Continue with [Create your first agent](./first-bot.mdx). The current runtime retains the existing data-directory and configuration names for compatibility.
